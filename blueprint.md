# Blueprint

## Overview

This project is a floral design portfolio website for Miss Pitimini. The goal is to create a visually appealing and modern website that showcases the floral designs of Sara Laínez.

## Project Outline

### Style and Design

*   **Color Palette:**
    *   Background: `#FDF5EA` (light cream)
    *   Text: `#2c3e50` (dark slate gray)
    *   Accent: `#E8A2A2` (soft pink)
*   **Typography:**
    *   Headings: "Playfair Display", serif
    *   Body: "Lato", sans-serif
*   **Layout:**
    *   Header with logo and navigation
    *   Hero section with a prominent image
    *   Gallery section to showcase projects
    *   About section
    *   Contact section
    *   Footer

### Features

*   **Header:** A simple header with the logo and navigation links.
*   **Hero Section:** A full-width hero section with a background image and a catchy headline.
*   **Gallery:** A grid of cards showcasing floral design projects.
*   **About Section:** A section with a picture of Sara Laínez and a brief bio.
*   **Contact Section:** A simple contact form.
*   **Footer:** A footer with social media links and contact information.
