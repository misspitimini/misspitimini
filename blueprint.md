# Visión General del Proyecto

Este proyecto es una aplicación web de static-first construida con Astro.js y diseñada para ser desarrollada en Firebase Studio. El objetivo es crear un sitio rápido, de alto rendimiento y escalable, que ofrezca un mínimo de JavaScript por defecto para garantizar una experiencia de usuario excepcional y unos Core Web Vitals de primer nivel.

## Resumen del Proyecto

El proyecto se centra en la creación de una floristería online llamada "Sara Laínez". El sitio web mostrará información sobre la floristería, sus productos (ramos, etc.), experiencias y eventos. También contará con una sección de blog para compartir consejos e inspiración sobre arreglos florales.

### Estilo y Diseño

- **Paleta de colores:** La paleta de colores se centra en tonos rosados, blancos y grises, creando una estética elegante y femenina.
- **Tipografía:** Se utilizan dos fuentes principales: una fuente display para los títulos y una fuente de cuerpo para el texto.
- **Iconografía:** Se utiliza un conjunto de iconos SVG personalizados para la navegación y otros elementos de la interfaz de usuario.
- **Imágenes:** Se utilizan imágenes de alta calidad de flores y arreglos florales para crear una experiencia visual atractiva.

### Características

- **Página de inicio:** La página de inicio da la bienvenida a los usuarios con una presentación de la floristería y sus servicios.
- **Página de ramos:** Muestra una galería de los ramos de flores disponibles para su compra.
- **Página de experiencias:** Informa sobre los próximos experiencias florales y permite a los usuarios inscribirse.
- **Página de eventos:** Presenta los servicios de decoración floral para bodas y otros eventos.
- **Página de blog:** Ofrece artículos con consejos y tendencias sobre el mundo de las flores.
- **Componentes reutilizables:** Se han creado componentes reutilizables para las tarjetas de ramos, experiencias y entradas de blog para mejorar la mantenibilidad del código.

## Plan Actual

El plan actual consiste en finalizar la refactorización de los componentes de la aplicación para mejorar la estructura del código y facilitar su mantenimiento a largo plazo. Una vez completada esta tarea, se procederá a unificar el estilo de los componentes para garantizar una experiencia de usuario coherente en todo el sitio web.
